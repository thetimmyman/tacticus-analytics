# Android module capability policy

The native preview does not load executable addon code. The release policy is builtin-vetted-only, with scoped native brokers and explicit per-operation consent. There is no arbitrary plugin host, JavaScript bridge, root access or access to another app's private files.

| Capability                                   | Preview                                            | Platform boundary / remaining work                                                                                                                                                                                     |
| -------------------------------------------- | -------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Player personal data                         | Official API through native Keystore broker        | Player mandatory; metadata scopes/expiry; display confirmation; no invented stable identity. Complete sanitized roster/inventory/progress retained locally.                                                            |
| Guild membership                             | Optional official Guild scope                      | Actual returned Guild ID; separate or combined vault refs; mismatch holds previous data.                                                                                                                               |
| Guild Raid                                   | Optional official scope                            | Same key must independently read Guild because Raid lacks Guild ID. Never infer a binding from an entered label or a local receipt.                                                                                    |
| Manual/historical rows                       | Authorized system-picker documents and local entry | Unverified, secret-free, isolated demo mode; no imported authority/consent.                                                                                                                                            |
| Guild War / Replay import                    | Not implemented                                    | No official source is asserted. A future vetted native module needs an owner-approved user export/protocol and strict broker adapter. Existing file/client readers cannot assume cross-app private storage on Android. |
| Remote addon catalog, install/update/execute | Unavailable                                        | Frozen broker/catalog contracts require native implementation and rights/security review. No arbitrary executable or remote asset is loaded by this preview.                                                           |
| Cloud contribution                           | Unavailable / default-off                          | Independent purpose-scoped consent and authority adapter required; official Player verification does not enable sharing.                                                                                               |

These unavailable modules remain blocked acceptance, not approved exclusions. The proprietary application licence is unchanged.
