# Android acceptance and remaining work

The initial native vertical slice is implemented and tested on installed synthetic emulator APKs. This does not satisfy the full package acceptance. The [feature matrix](feature-matrix.json) preserves all 339 provisional public source rows. Every row remains blocked pending native behavior and installed parity evidence; no exclusion is approved. The prototype's native capabilities below do not relabel any complete web feature as ported.

The protected release job is manual, main-only and names `android-release-signing`. The owner must configure and verify that environment's required reviewers/protection and existing `ANDROID_RELEASE_KEYSTORE_BASE64`, `ANDROID_RELEASE_STORE_PASSWORD`, `ANDROID_RELEASE_KEY_ALIAS`, `ANDROID_RELEASE_KEY_PASSWORD` secrets before using it. Naming an environment does not establish protection. The pipeline does not create/rotate an identity or publish to a store. Signed build output remains unqualified until physical and rights/security checks bind the exact source and artifact digest.

External gates: a physical Android phone and tablet under authorized release testing; an existing owner signing identity and configured protection; upstream credentials/protocol permissions for real scope checks; approved feature mapping and any exclusion decisions; official-source gaps for Guild War/Replays; rights/channel/security review. Implementation gates are listed separately above: full application parity, legacy/full portable migration, native addon adapters and live contribution integration still require code. These are not disguised as device blockers. Existing acceptance remains open.
