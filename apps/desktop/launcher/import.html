Supported file format

The versioned file contains format, guildCode, numeric season and an entries array. Each entry includes userId, type, encounterIndex, damageType (Battle or Bomb), damageDealt, remainingHp, maxHp, rarity, tier, set, and explicit startedOn/completedOn or timestamp values. Optional display names and supported unit metadata are preserved. Other export formats and nested equipment or ability metadata are refused. No partial import occurs if any entry fails validation.

This importer does not connect to the game or validate membership. Only import data you are entitled to keep. Never select a credentials file; unknown fields are rejected.
