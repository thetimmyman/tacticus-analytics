TACTICUS ANALYTICS · LOCAL PREVIEW

Open your local workspace

This preview runs on your computer. Create a sample workspace or an empty local workspace for supported raid-file imports. Local player labels do not verify ownership of a game account.

For a local file workspace, enter the guild code and player ID that appear in your raid files. These are local labels; no game connection or account verification occurs.

Save a recovery code

Enter your current password to create a recovery code. Save the code somewhere private outside this workspace. Anyone with this code can reset your workspace password. Creating a new code replaces the old one.

Forgot your password?

Use your saved recovery code to set a new password. Your analytics data stays in place. Without a saved code or password, this form cannot unlock your workspace.

No hosted account or email service is required. Keep your password safe; retry interrupted setup with the same password. Password recovery is available offline after you save a recovery code.
